## El reto

Diseñar una presencia digital para una pastelería académica que permita presentar la marca, recorrer categorías de productos y facilitar el contacto desde distintos dispositivos.

## Enfoque

El equipo estructuró la experiencia en una portada y cuatro recorridos de catálogo: productos, pastelería tradicional, pastelería gourmet y postres. La navegación y el estilo se mantienen consistentes entre páginas.

## Solución

El sitio combina HTML, CSS, JavaScript y Bootstrap. Los archivos revisados incluyen código fuente, imágenes, menús, documentación de alcance y una estructura de contenidos orientada a pequeños negocios.

## Aprendizajes

- Organizar información comercial en una arquitectura de navegación sencilla.
- Reutilizar patrones visuales entre páginas estáticas.
- Separar un prototipo frontend de capacidades que requerirían backend.

## Próximos pasos

Mejorar accesibilidad, optimizar recursos, reemplazar datos ficticios y conectar formularios solo después de definir un backend seguro.
