## El reto

Presentar de forma clara un servicio de internet inalámbrico y sus atributos principales mediante una navegación web sencilla.

## Enfoque

El prototipo organiza información institucional, servicios, cobertura, características y contacto. El material revisado incluye una página HTML, recursos de imagen y una captura del modelo visual.

## Alcance verificable

La evidencia confirma un ejercicio frontend estático. No permite afirmar que el servicio, los formularios o los canales comerciales hayan operado en producción.

## Aprendizajes

- Definir una jerarquía básica de contenidos para un servicio.
- Construir navegación y secciones informativas con HTML y CSS.
- Diferenciar una maqueta académica de una solución transaccional.

## Próximos pasos

Actualizar el diseño, revisar accesibilidad, normalizar la cronología de los archivos y documentar la autoría.
